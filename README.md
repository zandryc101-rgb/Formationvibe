# AdminPro

Dashboard administrateur PyQt5 (Python 3.10) avec SQLite.

## Lancement

```
pip install -r requirements.txt
python admin_dashboard.py
```

Les comptes admin (maximum 2) sont stockes dans `adminpro.db`.
Inscription, modification, suppression et recuperation de mot de passe
se font depuis l'ecran de connexion et la page Parametres.
